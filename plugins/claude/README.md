# Y2 Intel

Connect a Y2 workspace to find intelligence profiles, read existing reports with citations,
browse sourced signals and entities, and explore public geographic events on an interactive map.
Install this bundle in a host that supports portable plugins and remote MCP, then follow the
OAuth sign-in and workspace consent flow. No API key or local server is required.

Access requires an existing Y2 account and workspace with the corresponding intelligence and API
entitlements. Each connection has explicit read permissions and expires after 30 days. Manage or
revoke it in [Y2 Connections](https://y2.dev/app/settings/connections). The integration does not
modify records, generate new reports, initiate payments, or collect device location.

[Setup and support](https://y2.dev/docs/api/mcp) · [Privacy](https://y2.dev/privacy) ·
[Terms](https://y2.dev/terms)

Repository distribution is separate from OpenAI directory review and publication. See the release
evidence in this repository for the current submission and availability status.
